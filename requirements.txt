# Ring Fountain reproduction requirements
#
# Python >= 3.10 is required; the current workspace was verified with
# Python 3.14.4. Core Ring Fountain Python tools use only the standard library,
# so there are intentionally no project-wide PyPI packages below. The archived
# case-13 Drop-Impact and case-14 Bursting-Bubble audit plotters have isolated,
# optional dependency locks in their respective tools directories; they are not
# needed by the ring solver or to inspect the tracked evidence. On PEP 668 distributions,
# validate/install this file inside a virtual environment:
#
#   python3 -m venv .venv
#   .venv/bin/python -m pip install -r requirements.txt
#
# The CFD and rendering workflow also requires system software, which pip
# cannot install. Verified versions in WSL2 Ubuntu are listed for provenance;
# compatible versions are expected to work.
