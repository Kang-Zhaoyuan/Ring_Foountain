Status: **PASS**

The mandatory offline capsule path reproduced successfully in the isolated
`report/capsule_work/` copy. This is a figure/data/test reproduction, not a
local rerun of the L13--L15 HPC simulations.

- All 211 entries in `SHA256SUMS` passed both in the clean pinned checkout and
  after copying the complete capsule. `metadata.json`, `cases.csv`, the data
  licence and citation, `uv.lock`, Fig. 2(a)'s manifest, HPC environment record,

- `SINGULARJETS_NO_TEX=1 bash reproduce-fig2-v2.sh` exited 0. All output PNGs
  pass Pillow decoding. The corresponding PDF files exist and are non-empty.
- The exact requested `uv run --offline pytest` first attempted to re-resolve
  because uv 0.11.29 detected a changed global exclude-newer policy. The
  locked correction, `uv run --offline --frozen pytest`, used no network and
  passed all 7 regression tests. These tests pin the Fig. 2 numerical
  prefactors and point counts from `metadata.json`.

## Output comparison

Eleven of 23 committed PNG/PDF products remained byte-identical. The twelve
products regenerated by the primary Fig. 2 workflow changed bytes. This is not
reported as binary identity: PDFs can contain renderer metadata, and the PNG
renderer/font layout also differed. Quantitative PNG comparison is in
`tables/capsule_png_comparison.tsv`: four frame PNGs retain 98.8--99.2% exact
pixels; `fig2_v2.png` retains 96.78% exact pixels with mean absolute RGBA
difference 3.00/255; the standalone streamline panel changed height by five
pixels. The numerical regression suite nevertheless passed exactly.

## Optional-runner limitation

`reproduce-Oh0.03.sh`, `reproduce-Oh0.02297.sh`, and `reproduce_facets.sh`
were attempted both directly and inside the locked environment. Their scripts
hard-code `text.usetex=True`, so they stop when LaTeX is absent. The committed
products for these three paths remain byte-identical and readable. No capsule
script was edited and no system package or `sudo` was used. This optional
environment limitation does not invalidate the mandatory checksum, locked
Fig. 2 generation, or offline regression gates.
