# Source and license boundary

The reproduced upstream repository identifies itself as GPL-3.0. This case is
therefore intentionally an evidence-only migration, not a vendored copy.

## Included

- Text written during the audit: reports, commands, environment notes,
  interpretation, warnings, and open questions.
- Parameter files created from the pinned upstream defaults for the executed
  cases. These are factual key/value inputs, retained for result provenance;
  they do not contain the solver implementation.
- Numerical tables, PLIC coordinate output, plots, and captured process logs
  generated by the independent runs.
- `tools/analyze_results.py` and `tools/snapshot_metrics.c`, created during this
  audit. The C helper calls public Basilisk interfaces but does not copy an
  upstream Drop-Impact function. No compiled form is distributed here.

No new project-wide license is asserted for these project-created files; the
repository owner's eventual license decision remains authoritative.

## Excluded

- Every tracked or untracked file cloned from `comphy-lab/Drop-Impact`.
- The locally downloaded Basilisk installer and installed Basilisk tree.
- Upstream helper sources and their executables.
- Solver copies, executables, objects, restart files, intermediate dumps,
  videos, Git metadata, Python environments, and installed packages.

The upstream commit, installer hash, and Basilisk ref are factual references in
`source_lock.tsv`. Reproducing the calculation requires obtaining those sources
independently under their own license terms. Nothing in this directory should
be treated as permission to copy GPL code into the Ring Fountain solver.
