# ADR-001: Reference selection

Status: accepted for the validation foundation

The installed Basilisk source and its official tests are the primary compatibility authority. `rcsc-group/DropImpactViscousPool` is the primary external impact reference because it is linked to the target class of impact problems. `AndreWeiner/phd_basilisk` and `comphy-lab/Drop-Impact` are secondary references for project structure, parameter handling, and diagnostics. No external implementation is copied before license and version compatibility review.
